## 三、默认假设（未确认前按此执行）

- 模式工作名：**简洁模式 / 进阶模式**（已确认）。
- 新用户默认：本地 + 自动识别的系统待办；没有可用后端时自动“仅本地”。
- 不导入旧笔记待办；升级后提示“原有待办仍在系统 App”。
- 历史默认保留 90 天；已取件 30 天后可归档。
- 4.0 不做提醒/闹钟/日历；保留接口。
- 4.0 先保持 `compileSdk/targetSdk 34`；Stage 0 spike 通过再升。
- ColorOS 无真机则标记“社区验证”，不阻塞小米主线。
- 小组件默认 4×2，显示取件码；提供“只显示件数”开关。

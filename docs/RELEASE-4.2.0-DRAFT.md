## 零、文案优先级锁定（防止来回改）

4.2.0 起，**所有对外文案按同一个顺序写**，从用户价值高到低：

1. **桌面小组件** —— 4.2.0 的最大更新。讲「现在能用什么、有什么功能」，
   不要写「闪一下」「弹回桌面」「抛异常」这类开发过程描述。
2. **取件记录** —— 地点聚拢 / 时间倒序，以及「完整信息」看原文。
3. **规则集** —— 认得更准，单段码 / 运单尾号 / 混排码。
4. **提醒** —— 精确闹钟，到点就响；通知按码拆分。

**不列为更新要点**：更新日志本身、QQ 群入口。
（QQ 群按钮是更新弹窗里的常驻联系入口，之前已要求放在第一行，属于界面布局，不是更新内容。）

**三档文案的关系**：软件内弹窗 = 4 条要点（价值 + 功能，一屏不滚动）；
酷安 = 中等详略，同样 4 段；GitHub Release = 完整版，同样 4 节 + 升级须知。
**顺序和用词骨架必须一致，只做详略裁剪** —— 改一处就要同步另外两处。

发版前检查：三处第一条都是小组件、最后一条都是提醒，没有把开发细节写进用户文案。

## 三、酷安文案（单独写，不进仓库）

**标题**

```
取件码助手 V4.2.0｜待取件直接上桌面，还能按地点聚拢
```

**正文**

```
这版最值得试的是桌面小组件：把「还差几件没取」从 App 里搬到桌面上，
解锁手机就能看到，不用点进 App。

小组件里待取件的取件码、地点、来源一行一条，已取的划掉；
不想显示取件码可以关掉，只留件数。长按 App 图标选「添加小组件」就能加，
或者在设置页点添加。配色、透明度、字号、显示内容都能按喜好调，
设置时的预览和桌面看到的一样，边调边看就行。

取件记录新增两种排序：「时间倒序」和「地点聚拢」。
同地点的件归成一组，新短信来了整组顶到最上；
你在两个驿站都有件的话，去哪个取、各取几件，一眼就分清。
每条点「完整信息」还能看到当时的短信/通知原文，一键全文复制，不用再去短信箱翻。

规则集升到 v13，取件码认得更准：像「D-3704」这种单段字母-数字码，
以前会被拆成 3704 和运单尾号两个错码，现在能正确认出来；8A3K 这类混排码也能识别。
地点不再把「找店员」「您的包裹已到店」当成店名，淘宝那种「提醒你有件但不给码」
的推送也能正确取到码和来源。

提醒也不再晚点。以前用系统的不精确闹钟，选了 9:00 可能 9:1x 才响，
现在改成精确闹钟，到点就响。一条短信里有几个码，通知也分成几条，不再拼成一条看着像漏件。

升级后建议重启一次：通知 Hook 跑在系统进程里，LSPosed 只在进程启动时注入。
另外这一版小组件组件有调整，请到 LSPosed → 模块 → 取件码助手 → 作用域，
确认带「推荐应用」标记的「系统框架」等必需项都勾着，调整好再重启。
规则数据热更新即可，但上面提到的地点词表、淘宝通知、同码合并这几项要升级到本版才生效。
```

**更新日志（酷安简版）**


## 四、酷安评论回复模板

**Q：升级后要重启吗？**
```
建议重启一次。通知 Hook 跑在系统进程（system_server）里，
LSPosed 只在进程启动时注入；不重启的话通知通道还是旧代码。
```

**Q：小组件显示错乱 / 行距不对？**
```
长按小组件 → 移除 → 重新添加一次。
安卓桌面不会在 App 更新后重建已有小组件的视图树，
旧组件还是首次添加时的布局，只能移除重加。
```

**Q：为什么长按图标没有「添加小部件」？**
```
桌面长按菜单里的「添加小部件」是桌面自己控制的，部分 ROM 不向第三方应用显示。
请用桌面快捷方式里的「添加小组件」；进入小组件设置页后也可以点「添加小组件」按钮。
```

**Q：升级后 LSPosed 里推荐应用/作用域好像变了？**
```
覆盖安装后 LSPosed 可能刷新模块状态。请到 LSPosed → 模块 → 取件码助手 → 作用域，
确认带「推荐应用」标记的「系统框架」（英文 system，旧版叫「Android 系统」）等必需项都勾着，
确认完再重启手机。系统框架和 Android 系统指的是同一个进程，勾一个就行。
```

**Q：点添加没反应 / 只弹去开权限？**
```
到 系统设置 → 应用管理 → 取件码助手 → 权限管理 → 其他权限 → 桌面快捷方式，打开后回来再点一次。
MIUI / HyperOS 上这个权限关着时桌面会直接拒绝添加请求。
```

**Q：地址聚拢怎么理解？**
```
在取件记录页右上角切换「时间倒序 / 地址聚拢」。
地址聚拢按完整地点分组，同组的件排在一起，新短信来了整组顶到最上；
组内仍按时间倒序。「全部」页的已取件仍沉底、不分组。
```

**Q：规则 v13 需要升级 App 吗？**
```
规则数据会自动热更新，不用升级。但地点词表、淘宝通知来源、同码合并这几项
依赖引擎改动，需要升级到 4.2.0 才生效。minAppVersionCode 保持 405，
4.0.5 及以上都能正常拉到规则。
```

**Q：怎么联系作者 / 提 bug？**
```
开发者 QQ 群 901543676，进群备注「取件码助手」。
小组件出问题可以进小组件设置页点「小组件自检」→「复制诊断信息」，
把结果发群里，能直接定位是哪一处不兼容。
```

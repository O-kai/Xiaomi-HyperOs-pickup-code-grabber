## ① 核心大文章（老帖，替换原帖正文）

### 标题

【开源】取件码助手 · 快递取件码自动提取，一条短信都不用翻（LSPosed）

### ↓↓ 从这里复制

取件码这件小事，其实每天都在消耗你几秒钟：到驿站门口，掏手机，翻短信，
找那串 12-3-4567，念给店员听。碰上同事在旁边等你报码，这几秒会格外长。

取件码助手把这几步省掉了：短信或 App 通知里一出现取件码，它替你认出来、记下来；
要用的时候，首页第一屏就是，看一眼或者点一下复制都行。

━━━━━━━━━━

【它做了什么】

收到 → 认出来 → 记下来 → 放到眼前。

一、认出来

驿站短信（菜鸟、兔喜、妈妈驿站、丰巢、京东、顺丰、极兔…）和 App 通知
（菜鸟裹裹、淘宝、京东、拼多多、顺丰、丰巢、抖音…）都能识别。
取件码的写法五花八门——12-3-4567、A88123、CC3-3214、1023-a-66 都在覆盖范围内。
反过来说，「超时催取」「验证码」「账单」这类长得像、其实不是取件的信息会被挡掉。

二、记下来

落进本地数据库：带来源、地点、时间、状态，能搜索、能筛选、能导出。
超过一天没取会标「滞留 1 天」，超过七天标「滞留 7 天以上」——只是提醒，绝不自动删除。
取完点一下 ✓，进「已取」，历史一直都在。

三、放到眼前

· 首页「待取件」：点码复制，点 ✓ 标记已取
· 桌面小组件：每行一条常驻桌面，也可以让它只显示件数、不显示码
· 通知：取件码直接显示在通知上，点开就能复制
· 系统待办：需要的话，一码一条写进小米笔记 / ColorOS 日历待办，跟着系统提醒走

━━━━━━━━━━

【两个界面，各取所需】

· 简洁模式：一页看完——待取件、规则、写入目标、写入格式、链路测试，
  底部一个「更多选项」。适合只想看码、取件的人，不用在四个页面之间找东西。
· 进阶模式：首页 / 通知提取 / 高级规则 / 设置，规则、来源白名单、外观、
  组件、提醒都在这里。

两者随时切换，数据完全共享，切过去不会丢东西。

━━━━━━━━━━

【能自己调的地方】

· 写入格式：极简（纯码）/ 完整（码 + 来源 + 地点 + 时间）/ 自定义模板
· 写入目标：系统待办、软件内部记录，两块可以都开，也可以只留一块
· 桌面小组件：字号、是否显示取件码、是否显示地点
· 通知提取：哪些 App 的通知要读，可以自己加进白名单
· 自定义规则：自家驿站、学校自提柜写法特殊？按号码或正则单独写一条

━━━━━━━━━━

【它是怎么长成现在这样的】

推翻过两次。最早想靠「通知监听 + 手写 Xposed 桩」，模块显示已激活，钩子却从没被调用过；
按 LSPosed 的规范重写之后，才第一次真正抓到短信。中间那代把取件码写进系统待办——
能用，但拿别人家的待办库当数据库使，换个 ROM 就塌。

现在这一代反过来：本地库是事实源，写进系统待办只是同步出去的一份副本。
被推翻的决定、早期那些分析文档，都还留在仓库里，没有删。

━━━━━━━━━━

【能装在哪】

· 系统：小米 / 红米（MIUI、HyperOS）、一加 / OPPO（ColorOS 16）；Android 9 以上
· 前提：root（Magisk 或 KernelSU）+ LSPosed，没有这两样装上也用不了
· 作用域：Android 系统、电话、短信、com.android.providers.telephony；
  小米设备另勾「小米笔记」，ColorOS 另勾「日历」
· ⚠️「Android 系统」在作用域列表最底部、不带推荐角标，必须勾；
  不是名字很像的「系统框架」

ColorOS 说明：写入侧早就支持，但新架构里新增的三处专属适配（短信 Hook 类名、
冻结后的 Provider 唤醒、配置文件的 SELinux 标签）作者手上没有实机验证。
体检里有一项「ColorOS 唤醒」会告诉你适配目标还在不在，有问题带日志找作者。

━━━━━━━━━━

【别的系统？欢迎一起适配】

目前真正跑通过的是小米 / 红米和一加 / OPPO 两条线。vivo / iQOO、荣耀、三星、
摩托罗拉这些系统不是不愿意支持，是我手上没有机器——写出来也验证不了，
不敢直接塞进正式版让大家当白老鼠。

如果你正好有机器、也愿意折腾，三种方式都行：

· 会写代码的：直接提 PR。写入侧要改的其实不多，主要是找到那个 ROM 的待办 / 便签
  数据库在哪、字段长什么样，照着现有两个后端的写法补一个。
  短信 Hook 可能要补一下类名（ColorOS 当初就补过），通知提取基本不用动——它不吃 ROM 差异。
· 不会写但愿意测的：进群里说一声，我给你编测试包，你跑一遍把日志发我，我按日志改。
  ColorOS 的适配当初就是这么一条条对出来的。
· 只是想用：也欢迎进群催一句，人多的时候适配会快一点。

想法很朴素：只要是 root 过、装了 LSPosed 的机器，都该能用上。
机器在你手上，代码在我这儿，凑一起就成。

━━━━━━━━━━

【怎么装】

方式 A（推荐）：LSPosed 管理器里搜「取件码助手」，直接装。以后有新版本也在里面点更新。

方式 B：到 GitHub Releases 下载 APK 手动安装：
https://github.com/O-kai/Xiaomi-HyperOs-pickup-code-grabber/releases

装完三步：

1. LSPosed 里启用模块，按上面「能装在哪」勾好作用域
2. 重启手机（抓取逻辑跑在系统进程里，不重启不生效）
3. 打开 App → 点开首页状态卡 → 点「点击体检」，全绿就是好了

sqlite3 这些依赖由 App 自己部署到应用私有目录，不需要手动推文件，也不用装 Termux。

━━━━━━━━━━

【这一版：4.0.3，识别规则集 v9】

写入目标回到两处

系统待办 + 软件内部记录，默认都开，也可以只留一个。
桌面小组件不是第三个目标——它读的就是内部记录，所以关掉记录，组件也会一起从桌面移除。
（想让平板、另一台手机也看到码，就开着系统待办，它跟着你的系统账号同步。）

新：简洁模式

只有一页：待取件、规则、写入目标、写入格式、链路测试，底部一个「更多选项」。
不想在四个页面里翻东西的人，用这个就够。

规则 v9：把「假取件」挡掉

电商会推「商品待取件提醒」「订单发货通知」这种——含「取件」「快递」字样，但根本不给码。
以前它们会被当成「疑似漏抓」塞满错题本，现在整条跳过。

顺手修的几处

· 一键链路测试现在真的写一条：待办里有、App 里有、组件跟着刷新，不再是「只写一半」
· 关掉内部记录会真正清空本地库（之前在主线程调库，异常被吞成「删除 0 条」）
· 首页「一键链路测试」不再被底栏压住、点不到
· 错题本清空后，条数立刻刷新
· 设置页去掉一层套娃弹窗，错题本 / QQ 群 / 酷安主页直接列出来

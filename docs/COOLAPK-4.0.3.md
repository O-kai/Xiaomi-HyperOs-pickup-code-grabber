## ① 老帖更新（替换原帖正文）

### 标题

取件码助手 4.0.3｜取件码回到本地，待办只是同步出去的一份

### 正文

当前版本 **4.0.3**，识别规则集 **v9**。

这个模块做的事很简单：短信或 App 通知里出现取件码，它替你认出来、记下来，
要用的时候一眼就能看到。

4.0 是一次彻底重写，不是加功能。之前把小米笔记的待办库当成"数据库"用——
听起来聪明，实际上很别扭：换个 ROM 就塌，取件码到底存在哪也说不清。
现在反过来：本地库是事实源，写进系统待办只是"同步出去的一份副本"。

这次 4.0.3 又收了二十多处细节，挑重要的说：

【写入目标只有两处，默认都开】

· 系统待办：写进小米笔记的待办列表（ColorOS 是日历待办或便签）
· 软件内部记录：App 顶部显示「待取件」，桌面小组件读的也是它

桌面小组件不是一个独立目标——它没有自己的库，只是内部记录的展示。
所以关掉内部记录时，App 内的记录清空、首页整块消失、组件也从桌面移除；
重新打开就都回来了。

两处至少留一个。只想在 App 里看码、不想让笔记里多一堆待办，就把系统待办关掉。

【简洁模式】

只有一页：待取件、规则、写入目标、写入格式、链路测试，底部一个「更多选项」。
不想在四个 Tab 里找东西的人用这个就够，数据和进阶模式完全共享。

【识别规则 v9】

新增一类「纯状态通知」的拦截。电商平台会推「商品待取件提醒」「订单发货通知」
这类消息——含"取件""快递"字样，但根本不给码，只是告诉你"有件了"。
以前它们会被当成"疑似漏抓"记进错题本，现在整条跳过，错题本干净了。

【其他】

· 桌面小组件：「显示取件码」改成上级开关，关掉只显示件数；「显示取件地点」在它下面
· 链路测试现在真的写一条：待办里有、App 里也有、组件跟着刷新，不再是"只写一半"
· 错题本清空后条数立刻刷新，不用退出去再进来
· 设置页去掉了一层「反馈与支持」弹窗，错题本 / QQ 群 / 酷安主页直接列出来
· 关于里的「复制 JSON 诊断报告」和 GitHub Issue 入口删了，排查向导里的导出还在

【安装要求，先看这段】

1. LSPosed 启用模块；
2. 作用域必勾「Android 系统」（列表最底部、没有推荐角标的那一项），
   再加电话、短信、com.android.providers.telephony，小米设备另勾「小米笔记」；
3. 需要 root（Magisk / KernelSU），写入待办要读写系统库；
4. 勾完作用域必须重启手机。

装完打开 App，点开首页状态卡 → 点「体检」，全绿就是好了。

## ② 新版本引流帖（新发一条）

### 标题

取件码助手｜取件短信一到，码就躺在你手边

### 正文

取件码这东西很烦：散在驿站短信、快递柜通知、电商 App 的推送里，格式还各不相同。
取件的时候翻半天聊天记录，翻到的时候可能已经过期了。

先说清楚门槛：**要 LSPosed + root**，没有的话装了也用不了，别白折腾。
（HyperOS / MIUI、ColorOS 16 都可以，Android 9 以上。）

这个 LSPosed 模块干三件事：

一、认出来
短信和 App 通知里的取件码都能提取。菜鸟、菜鸟裹裹、京东、淘宝、拼多多、顺丰、
丰巢、抖音默认支持，别的 App 可以自己加白名单。

二、记下来
落进本地库，带状态、地点、时间。能搜索、能筛选、能导出，超过一天没取的会标
「滞留 N 天」——只是提醒，绝不自动删除。

三、放到眼前
首页最上面就是待取件，点码复制、点 ✓ 标记已取；桌面小组件常驻；
需要的话还能同步进系统待办（小米笔记 / ColorOS 日历·便签）。

这里有个区别值得说清楚：软件自己的记录只在这台手机上；
想同步到平板、另一台手机，就开着「系统待办」——写进去的那条是系统待办 App 的数据，
它有自己的账号同步。模块本身不联网，除了查更新。

4.0 是彻底重写：本地库成了唯一事实源，写待办降级成"同步出去的一份副本"。
好处是换个 ROM 不会塌，取件码存在哪也说得清。

4.0.3 这版还加了：
· 简洁模式——只有一页，不用在四个 Tab 里找
· 「显示取件码」改成上级开关，关掉只显示件数，同事瞥一眼也看不到码
· 识别规则 v9——电商那种"提醒你有件了但不给码"的推送，不会再被误判

要求：LSPosed + root。作用域必须勾「Android 系统」（列表最底下那项），勾完重启。

# 【取件码助手】剪映极简剪辑与成片实操指南

> **适用场景**：你睡醒后，花 10~15 分钟在电脑上打开“剪映”，把录屏素材拼合配音，直接导出成片。
> **工具**：剪映电脑版（免费、无水印、功能极其傻瓜化）。

---

## 一、素材准备

- **真机演示素材目录**：`docs/video-strategy/recordings/`
  - `01_Scene1_Arrival_Notification.mp4`（已录制完毕，真实演示短信到站、通知栏复制与已取件）
  - 如果手机重新连上电脑，运行 `D:\project\_build-tools\record-demo-videos.ps1` 还能全自动录出场景二（设置页）与场景三（错题本）。
- **脚本分镜文案**：`docs/video-strategy/03-video-scripts.md`（内含 4 套平台解说词）

---

## 二、剪映 5 步成片工作流（极简图解）

```
 [1. 导入视频]  ──►  [2. 粘贴文本]  ──►  [3. 一键朗读]  ──►  [4. 智能字幕]  ──►  [5. 导出视频]
  将录屏拖入轨道       复制分镜旁白       选AI青年解说音      一键自动对齐语音      1080P/60帧直接出片
```

### 详细步骤：

1. **新建草稿与比例设置**：
   - 打开剪映 ➔ 点击“开始创作”；
   - 播放器右下角选择画面比例：
     - **抖音 / 小红书 / 视频号**：选择 **`9:16`**（竖屏）；
     - **B站**：选择 **`16:9`**（横屏）。
2. **拖入录屏视频**：
   - 把 `recordings/` 目录下的实机录屏视频直接拖进下方的“视频主轨道”；
   - 视频两端多余的静止画面，用快捷键 `Ctrl + B` 剪切，按 `Delete` 删掉。
3. **粘贴旁白与 AI 一键配音（绝杀提效！）**：
   - 从 `03-video-scripts.md` 复制你选定平台的“旁白解说词”；
   - 在剪映上方点击 **“文本” ➔ “新建文本” ➔ “默认文本”**，把整篇旁白粘贴进去；
   - 选中这个文本块，在右上角面板点击 **“朗读”**（Text to Speech）：
     - 推荐音色：选择 **“科技小哥”**、**“阳光青年”** 或 **“沉稳男播”**；
     - 点击“开始朗读”，剪映会在 3 秒内自动生成极度自然的声音音轨！
4. **一键生成字幕**：
   - 点击上方菜单 **“文本” ➔ “智能字幕” ➔ “文稿匹配”** 或 **“识别歌词/语音”**；
   - 剪映会自动把文字拆成一句句字幕并精确卡点在语音下方；
   - 在右侧面板挑一个喜欢的花字样式（推荐：黄字黑边，醒目清爽）。
5. **添加免版权背景音乐 (BGM)**：
   - 在左上角点击 **“音频” ➔ “音乐”**，搜索：`科技`、`轻快`、`节奏卡点` 或 `治愈`；
   - 把音乐拖入音频轨道，**音量调节到 -18dB 到 -22dB**（作为背景微风声，切勿盖过人声）。
6. **导出**：
   - 点击右上角蓝色 **“导出”** 按钮；
   - 分辨率选择 `1080P`，码率选择 `更高`，帧率选择 `60fps`；
   - 点击导出，一气呵成！

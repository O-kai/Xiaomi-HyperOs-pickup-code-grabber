# 视频发布后高频疑问答疑应急库 (FAQ SOP)

> **使用方法**：视频发布后的 24~48 小时是互动黄金期，评论区提问量会激增。直接在本文件中按关键词 `Ctrl + F` 搜索问题，**复制右侧官方统一回复话术**，粘贴即可，省时得体又专业！

---

| 序号 | 评论区高频问题 | 官方标准回复模板（直接复制） |
| :---: | :--- | :--- |
| **Q1** | **“苹果/iPhone能用吗？”** | “暂时无法支持哦~ 本项目是基于安卓底层系统框架（LSPosed）实现的深度联动，iOS 系统的封闭机制无法实现免权限短信底层拦截，苹果用户暂时无缘啦 🍎” |
| **Q2** | **“华为 / 荣耀 / vivo / 三星 能用吗？”** | “目前官方完美适配了【小米/红米 (MIUI/HyperOS)】和【一加/OPPO (ColorOS 16)】。其他品牌只要能解 BL 锁并刷入 LSPosed 也可以尝试，但由于各家待办/备忘录数据库结构不同，需要社区小伙伴一起适配哦，感兴趣可以来开源仓库看看～” |
| **Q3** | **“没 Root 能用吗？普通手机怎么用？”** | “目前必须需要手机获取 Root（Magisk 或 KernelSU）并安装 LSPosed 框架哦。因为只有在底层框架拦截，才能做到‘不给短信读取权限、不常驻杀后台’的极致无感体验。新手小白不建议为了这个单独去刷机，常玩机的朋友可以放心冲！” |
| **Q4** | **“安全吗？会不会偷看我的短信？”** | “100% 安全透明！项目在 GitHub 完全开源（MIT 协议，全网任何人都能审计代码）。模块本体【零短信读取敏感权限】，完全是在系统底层短信入库点由系统传递数据，全程纯本地运算，甚至支持在设置中开启‘纯离线模式’，断网也能正常用，绝不上传任何隐私 🔒” |
| **Q5** | **“安装收费吗？有广告吗？”** | “完全免费！没有任何开屏广告、横幅广告或收费弹窗，纯粹是个人业余时间为了自己生活方便写出来的开源作品。觉得好用的话，去 GitHub 给个免费的 Star 就是对作者最大的支持啦 ⭐” |
| **Q6** | **“为什么我装完之后收到短信没反应？”** | “可以按这 3 步排查下：<br>1. LSPosed 里勾选模块后，必须【完整重启一次手机】；<br>2. 作用域里一定要确认勾选了列表最底部的‘Android 系统’（不带推荐标的那项）；<br>3. 打开 App 点一次‘一键测试’，按提示允许一次权限即可～有问题可在 App 菜单里点‘排查问题’一键自测！” |
| **Q7** | **“淘宝/菜鸟App里的取件码能抓到吗？还是只能短信？”** | “目前最新版本（v2.9+）已经加入了【通知取件提取】功能！支持直接拦截菜鸟裹裹、京东、淘宝、拼多多等 App 弹出的取件通知，短信和通知双通道自动去重，不用担心漏抓～” |
| **Q8** | **“我有个本地小驿站的短信抓不到怎么办？”** | “可以在 App 右上角‘⋮’里打开【疑似漏抓错题本】，点击‘手动上报’，把脱敏后的短信格式发在反馈区或者群里，我们会把你的短信规则加入到算法库中，3天内就会自动热更新生效！” |
| **Q9** | **“取完快递后怎么标记完成？”** | “有两种最爽的姿势：<br>1. 收到取件码通知时，卡片上自带‘已取件’按钮，点一下就自动打勾；<br>2. 直接在系统自带的待办小组件或笔记待办里，点击勾选框完成归档 📦” |

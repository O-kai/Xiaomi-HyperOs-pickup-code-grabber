4.0 是一次彻底重写：**本地库成为唯一事实源**，写进系统待办降级为「同步出去的一份副本」。
4.0.3 是重写后的第一轮集中收口，二十多处改动，挑影响使用的说。

### 写入目标只有两处，默认都开

| 目标 | 表现 |
|---|---|
| 系统待办 | 小米笔记待办；ColorOS 是日历待办与便签（两个独立的库，可同时写） |
| 软件内部记录 | 首页顶部「待取件」，桌面小组件读的也是它 |

桌面小组件不是一个独立目标——它没有自己的库，只是内部记录的展示投影。
关掉内部记录时：App 内记录清空、首页整块消失、组件也从桌面移除；重新打开就都回来。
两处至少留一个。

**为什么已经有本地记录还要系统待办**：它跟着小米账号 / OPPO 账号云同步，
同账号的平板、另一台手机也能收到；内部记录只在这台手机上。

### 简洁模式

只有一页：待取件、规则、写入目标、写入格式、链路测试，底部一个「更多选项」。
不用在四个 Tab 里找东西，数据和进阶模式完全共享。

### 识别规则 v9

新增「纯状态通知」拦截：电商推的「商品待取件提醒」「订单发货通知」这类消息，
含「取件」「快递」字样但根本不给码，以前会被当成「疑似漏抓」记进错题本，
现在整条跳过。词条刻意用带平台的完整标题，避免误杀驿站真实的「待取件提醒」。

### 桌面小组件

「显示取件码」改成上级开关，关掉只显示件数；「显示取件地点」在它下面，
码不显示时自动失效（保留你的选择，重新打开码就恢复）。

### 其他修复

- 一键链路测试现在真的写一条：待办里有、App 里也有、组件跟着刷新，不再是「只写一半」
- 关掉内部记录会真正清空本地库（之前在主线程调 Room，异常被吞成「删除 0 条」）
- 错题本清空后条数立刻刷新，不用退出去再进来
- 首页「一键链路测试」不再被底栏压住、点不到
- 设置页去掉一层「反馈与支持」弹窗，错题本 / QQ 群 / 酷安主页直接列出
- 删掉「复制 JSON 诊断报告」和 GitHub Issue 入口；排查向导里的导出报告保留

### 升级注意

1. **装完重启手机**：抓取逻辑跑在系统进程里，LSPosed 只在进程启动时注入；
2. 桌面小组件如果显示错乱，长按移除后重加一次；
3. 从 3.x 升上来的：写入目标会迁移成「系统待办 + 内部记录」，不会动已有记录。

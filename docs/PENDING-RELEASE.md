4. **把解析搬到 App 进程（架构级）**
   现在解析跑在 system_server，任何解析逻辑的改动都要重启才生效。
   若改成 hook 只转发短信原文、解析在 App 进程完成，则以后规则与解析的改动都不再需要重启。
   代价：跨进程传原文的时机与去重要重新设计，且抓取失败时少一层兜底。

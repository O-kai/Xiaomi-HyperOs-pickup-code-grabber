## 把「多平台」功能移植到新 UI

旧实现是给 TextView 套 SpannableString + ClickableSpan。PR #8 把这一行
改成了 UiKit.row(...)，副标题参数是 String，无法直接传 Span。

做法：
- 给 UiKit.row 增加一个 CharSequence 重载（保留 String 版本，既有调用点不变），
  内部检测到 ClickableSpan 时自动挂 LinkMovementMethod + 透明高亮
- 新增 buildNotiSubtitle() 生成带 Span 的副标题
  「拦截菜鸟 / 京东 / 淘宝 / 拼多多等 App 的取件通知 · 查看多平台」
  只给「多平台」三个字加点击与主题色加粗，避免整行可点造成误触
  （同一行右侧还有开关）
- 弹窗改用 UiKit.dialog（PR #8 已把系统 AlertDialog 全量替换为自绘套件）

## 数据来源

弹窗列表来自 NotiHook.currentPkgs()（内置 + 用户追加），不是写死的常量，
这样用户自己加了包名也能立刻看到，不会出现「设置里有、列表里没有」。

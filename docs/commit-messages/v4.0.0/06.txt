## 新增 tools/device-probe/

把 5 个零散脚本合并重写成一个参数化工具：

  python probe.py doctor                     检查设备前置条件
  python probe.py info                       打印设备完整信息
  python probe.py inject "短信" --code 6-4-3009  注入并自动判定 PASS/FAIL
  python probe.py list --limit 10            查看小米笔记待办
  python probe.py ui                         截屏

比原来好在：
- 一个入口覆盖全部场景，不用记 5 个文件名
- --code 自动判定 PASS/FAIL
- 能区分「没识别」和「去重命中」这两种 result=[]
- 路径可配置（ADB_PATH 环境变量），换机器能用
- 附 README.md 说明用法和坑

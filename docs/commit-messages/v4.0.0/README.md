## 为什么单独留档

git commit 说明一旦重写或压缩就难找回，而这些说明里有大量**排查过程**：
每条 bug 的现象、根因、为什么这样修、验证结果。这些是下一次遇到同类问题
最省时间的材料，值得独立保存一份。

## 替换规则

- 只放**当前版本**的图；旧图移到 `docs/legacy/screenshots/`，不要直接删（历史文档还在引用）。
- 截图前先确认画面上没有真实取件码、真实地址、手机号、桌面日历/备忘等内容。
- 宽度 600px 足够（GitHub 正文区约 800px），再大只是让仓库变胖。
- 引用方式：`![首页](docs/screenshots/home.png)`

## 小组件那张图的来源

`widget.png` 不是桌面截图，而是 App 内「设置 → 桌面小组件 → 小组件自检 → 真实渲染」出来的画面
（`RemoteViews.apply()` 真实 inflate，示例数据）。好处是：不受桌面壁纸/图标干扰，
也不会把个人桌面拍进去。

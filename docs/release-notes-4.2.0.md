4.2.0 的主角是**桌面小组件**：现在可以把待取件直接摆到桌面上，解锁手机就能看到还差几件没取，不用点进 App。这一版也把取件记录、识别规则和取件提醒顺了一遍。

老用户升级后原来的用法都还在，不用重新学。

### 桌面小组件：待取件就在桌面上

这是 4.2.0 最值得试的功能——把「还差几件没取」从 App 里搬到桌面上。

**能看到什么**

- 待取件的取件码、地点、来源，一行一条；已取件的划掉，和待取的区分开
- 关掉「显示取件码」时只显示件数，适合桌面隐私场景
- 待取件数、已取件数直接写在标题上，扫一眼就知道

**怎么加到桌面**

- 长按 App 图标 →「添加小组件」，直接落到桌面的添加确认框
- 或者进 App 的「桌面小组件」设置页，点「添加小组件」按钮

**能调成什么样**

- 配色：彩虹 / 夕阳 / 极光 / 樱花 / 单色，也有 24 色自定义
- 透明度七档，从实底到全透，配什么壁纸都能搭
- 字号、显示内容（取件码、地点、✓、已取件）都能按自己的习惯调
- 设置页里的预览和桌面看到的样子一致，边调边看，不用反复添加试

从旧版升上来的组件如果显示错乱，长按组件「移除」后重新添加一次即可。

### 取件记录：按地点聚拢，或按时间倒序

列表右上角新增排序切换：**时间倒序**和**地址聚拢**。

- **时间倒序**：最新收到的在最上面，和原来一样
- **地址聚拢**：同一个地点的件归成一组，组内按时间倒序；新短信来了，整个分组连同组里的旧件一起顶到最上面。比如你在两个驿站都有件，去哪个驿站取、各取几件，一眼就能分清

地址按完整地点分组，不会把不同分店混在一起；识别不出地点的记录单独成组，也按自己的时间参与排序，不固定沉底。

「全部」页里已取件仍然统一沉在下面、固定时间倒序，不会塞进未取件的分组里占地方；「待取」和「已取」页都可以自由切换两种排序。搜索只作用于当前页，和排序叠加使用。

每条记录还多了「完整信息」按钮（在「复制」左边）：点开就地展开，能看到这条记录当时收到的所有短信/通知原文，带来源类型和时间；底部「全文复制」只复制这些原文。解析好的取件码继续走原来的「复制」按钮，两条路互不干扰。

### 规则集 v13：取件码认得更准

真机样本：

```
【菜鸟驿站】取件码D-3704的韵达81913包裹到派出所南隔壁快递站，请19:00前取
```

v11 会提取出 `3704` 和 `81913` 两个码——**两个都不对**。真实的取件码是 `D-3704`（前面的字母和横杠都是码的一部分），`81913` 是韵达的运单尾号。

规则数据改了三处：

- 单段「字母-数字」码形（`D-3704` / `C-2605` / `M-2`）通过形状校验，不再被拆成两个错码；纯数字仍要求至少两段，裸数字不会因此变成合法码
- 承运商名（韵达/中通/圆通/申通/顺丰/邮政/EMS/极兔…）后紧跟的纯数字按运单尾号排除
- 物流状态词（已发货/已发出/已寄出/已揽收/已签收/派送中/运输中）不再被当成取件码

同一波还补了数字字母混排码（`8A3K` / `A3K8`），语料从 144 条扩到 179 条。

地点识别也改成词表驱动：以前「店领」「您的包裹已到店」「找店员」会被当成店名，现在这些词写在规则里，以后调整**不用发版**，热更新就能生效。淘宝那种「提醒你有件但不给码」的推送现在也能正确取到码（如 `1-9-7026`），来源写成「淘宝通知」，地点写成「菜鸟驿站」。

同一个包裹先来短信、后来通知，也不会互相覆盖了——后到的非空信息补进去，空值保留原来的，两条合成一条完整的。

### 提醒：到点就响

以前用系统的不精确闹钟，系统按省电窗口批量推迟，选了 9:00 可能 9:1x 才响。现在改成精确闹钟，到点就响；没给精确闹钟权限时会降级并给「去开启」入口。

一条短信里有多个取件码时，通知也按取件码拆成多条——以前拼成一条，看着像漏了一个。第 2 条起走静默渠道，不连响。提醒时间的选择器换成滚轮，点几下就能选好。

### 还有一些小地方

这几条没有单独拿出来讲，但都是日常会碰到、用起来会顺手一点的地方，留给大家自己发现：

- 已取件的**地址也一起划掉**，不再只有取件码有线、地点还是好好写着的，两种状态一眼分得清
- 小组件预览里固定画「两个待取 + 一个已取」，标题写的条数和实际画出来的一致，不会出现标题说 1 条已取、下面却一条都没有
- 取件码上的删除线只留一条。中文之前为了凑「双线」叠了下划线，看着像字底下划了一道，反而别扭
- 单色配色的小字现在显示真实色值（比如 `#1C1C1E`），不再只写「单色」两个字；透明度七档的字色按各自底色调过，浅色板上不会出现白底白字
- 选颜色不改预览就先关掉色盘 —— 点色只会变预览，点「确定」才真的存下来，试色试到一半反悔也不会留下痕迹
- 改主题、透明度、配色时不再整页刷新，预览不会闪一下、滚动位置也不会突然回到顶部
- 小组件预览底部给系统手势条留了位置，不会有一块灰带挡住内容
- 无障碍服务改了个一眼能认出来的名字：「取件码助手 - 桌面位置读取」，在列表里不会不知道是哪个 App 的
- 「重新校准」只在当前是估算时才提示，已经精确对齐过就不会再烦你
- 小组件设置页里「小组件自检」还在，页面精简成了「跑一遍 → 复制结果 → 发群」：复制出来的内容带版本号、机型和三项检查结果，发到群里能直接定位是哪一处不兼容
- 首页版本号可以点开看当前版本的要点；开发者 QQ 群在设置页最上面，「复制」按钮一点就复制群号
- 界面模式的「简洁 / 进阶」在两个地方长得一样、行为一样 —— 两处都是两段开关，点另一个就直接切，不用先进弹窗才发现能换

### 升级须知

- **建议重启一次**：`NotiHook` 跑在 `system_server`，LSPosed 只在进程启动时注入。不重启的话通知通道还是旧代码
- **顺便确认一遍 LSPosed 作用域**：这一版小组件相关组件有调整（新增了「添加小组件」的导出中转页），覆盖安装后 LSPosed 里的模块状态/推荐应用可能刷新。请到 LSPosed → 模块 → 取件码助手 → 作用域，确认带「推荐应用」标记的「系统框架」（英文 `system`，旧版叫「Android 系统」）等必需项都勾着，调整好再重启。
- **规则集 v13 热更新即可**：规则数据不需要升级 App；但地点词表、淘宝通知来源、同码合并这几项依赖引擎改动，需要升到本版才生效。`minAppVersionCode` 保持 405，4.0.5 及以上都能拉到规则

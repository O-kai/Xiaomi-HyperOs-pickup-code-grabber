## 为什么没有直接合并

这个 PR 的 base 是 `main`（= 3.1.0），而维护分支 `release/4.0` 已经比它领先
62 个提交，期间的界面是**按同一套思路重新实现**的：

- 技术路线相同：`Java + UiKit`，不引入 Compose（见 `docs/DECISIONS.md` D-17）；
- 底部同样收敛成 Tab，但分组不同（首页 / 通知提取 / 高级规则 / 设置）；
- 图标做成「主题色圆角底砖 + 前景图形」的统一派系，
  跟随设置里的外观配色（米金 / 雾霾蓝 / 青瓷绿 / 藕荷玫瑰）；
- 额外补了一批这一版才有的东西：状态卡校验清单、记录页管理面板、
  小组件自适应、深色模式对比度修正。

所以现在的 4.0 并不是「没用你这个 PR」，而是**同一件事后来又走了一遍**，
直接合并会产生大面积冲突，也没有功能增量。

这个目录里是 **4.0 之前**的分析、规划与阶段报告。**它们没有被删掉，但也不再维护**——
放在这里只是因为「删了可惜、留着会误导」。

> [README](../../README.md) 与 [`docs/ARCHITECTURE-4.0.md`](../ARCHITECTURE-4.0.md)。
> 这个目录里的结论有相当一部分已经被 4.0 的实现推翻。**

## 为什么这些文档会过时

4.0 不是 3.x 的延续，而是**一次重写**：

| 方面 | 3.x / 规划期 | 4.0 实际做法 |
|---|---|---|
| 数据归属 | 取件信息写进「小米笔记」的待办，笔记库是事实源 | **本地库（Room）是事实源**，写待办降级为「同步出去的一个副本」 |
| 跨进程入口 | 导出的广播 receiver | **只留 Provider 一个入口**（广播任何 App 都能伪造，已删除） |
| 界面 | 单页 + 弹窗堆叠 | Java + UiKit 自绘，四区域导航 + 桌面小组件 |
| 版本号 | `VERSION_NAME` 带 `-internal` / `-rc2` 等后缀 | 点分 `V4.0.3` + 独立 `VERSION_CODE` |
| 卸载残留 | sqlite3 部署在 `/data/local/tmp` | 搬到应用私有目录，卸载随数据删除 |

所以下面这些文档里关于「待办库结构」「广播入口」「界面结构」的描述，
**现在读会得到错误结论**。

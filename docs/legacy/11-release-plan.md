## 一、产品形态定稿（发布视角）

- **名称**：取件码助手（PickupCodeGrabber），包名 `com.pickupcode.grabber`
- **类型**：LSPosed 模块 App（安装到手机 + LSPosed 中激活；内含设置页与取件码列表）
- **核心闭环**：短信/通知捕获 → 提取 → 去重 → 写入小米笔记"待办"（一码一条、默认置顶堆栈）
  → 通知（点击复制）- 用户在待办里勾选完成
- **环境门槛**：Android 12+，root（Magisk）+ LSPosed；MIUI/HyperOS 12~17 声称支持，
  文档标注实测矩阵

## 二、设置页设计（美化 + 功能入口）

采用 Material Design 3（浅色/深色/跟随系统）：

| 区域 | 内容 |
|---|---|
| 顶部状态卡 | 模块激活状态 / 便签写入状态（检测 todo.db 可写性）/ 最近一次捕获时间 |
| 模板设置 | 三档切换：极简 / 完整 / 自定义占位符（`{code}` `{source}` `{place}` `{time}` `{raw}`），带**实时预览** |
| 捕获设置 | 短信通道开关；通知监听副通道开关（需授权引导）；"免打扰时段"（如 23:00-7:00 只写待办不弹通知） |
| 去重设置 | 默认"码+地点"策略；可选"仅码值"（激进） |
| 备份恢复 | 每日备份开关（/data/adb/pickup/backup/，保留 14 份）；立即备份 / 立即恢复按钮 |
| 待办管理 | 打开便签 App；跳转待办页；显示已写入条数 |
| 取件码列表 | 模块内历史（最近 50 条，分页）；搜索；复制；删除记录（仅删模块记录，不删便签） |
| 高级 | 自定义正则覆盖；黑名单关键词（如 12306/银行）；日志导出（调试）；关于/免责声明 |

## 三、功能细节盘查（候选增强，标注优先级）

| # | 增强 | 说明 | 优先级 |
|---|---|---|---|
| 1 | 通知"复制"按钮（Action Button） | 点通知本体=复制+打开便签；追加按钮：已取件（联动更新待办 is_finish） | 高（v2.1.1 已做"已取件"按钮） |
| 2 | 当日汇总通知分组 | 多码到达时合成一条（NotificationGroup），减少刷屏 | 中 |
| 3 | 桌面小组件 | 显示最近 5 条未取件码，点击复制 | 中（v2.1.2 起：**用户决定暂缓/移除**，MIUI 自带待办组件已覆盖） |
| 4 | 长按立即复制 | 通知正文长按复制（MIUI 支持则免费） | 低 |
| 5 | 历史统计 | 周/月取件数图表（纯本地） | 低 |
| 6 | 自定义正则（高级模式） | 满足特殊格式需求；提供默认模板 | 中 |
| 7 | 黑名单关键词 | 过滤 12306/银行/广告数字误报 | 高（v2.1.1 已做：预览+修改/保存） |
| 8 | 已取件自动标记（可选） | 默认关闭（用户选择手动勾选）；开启后支持"凭逻辑"自动标记为完成 | 低 |
| 9 | 深链接 | `pickup://codes` 直接打开列表；提供快捷方式（桌面图标直达） | 低 |
| 10 | 云同步提示 | 直写不触碰小米云同步字段，无法保证云端一致 → 设置页明确提示 | 发布必做 |
| 11 | 一键测试 | 随机码全链路自检，零短信费 | ✅ v2.1.1 已做 |

## 四、发布规划（路线）
